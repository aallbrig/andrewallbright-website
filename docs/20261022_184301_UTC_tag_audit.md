# Blog category and tag audit

Audited on 2026-10-22 against the live site (WordPress 7.1.3): 45 published posts and 12 drafts.
Nothing on the live site was changed by this audit. The proposals below are ready to apply with `scripts/wp.sh --confirm` once approved.

## Summary

- 39 of 45 published posts have no tags at all, so the tag cloud shows almost none of the technologies this blog demonstrates.
- Categories are doing double duty as topics. `Game Programming` (23 posts) and `Software Engineering` (17) hold more than half of everything.
- 12 posts look mislabeled, and 6 more have a weak or redundant category. Details are below.
- Several taxonomy terms are broken or duplicated. See "Taxonomy hygiene".

## Weak or redundant categories (judgment calls)

- **My thoughts on Web 1.0 versus Web 3.0 (181):** category `web 3.0` holds a single post and duplicates the tag `Web 3.0`. Move it to Software Engineering and keep one tag.
- **How to Efficiently Play Through Games (123):** about playing games, not building them. It has no good fit, so consider a small `Gaming` category or leave it in Game Programming.
- **Brand New Unity Project: My Starter Kit (310):** mostly CI and deploy (Game CI, GitHub Actions, GitHub Pages). Add Platform Engineering.
- **Global Game Jam 2022: Retro (184):** heavy on testing and CI. Add tags for those, and consider Platform Engineering.
- **I Recommend: Steve Rabin's Code Optimization DevDeck (3316):** the Optimization category is right. Add Game Programming, since the author comes from Game AI Pro.
- **Impressed with Grokipedia's Game Programming Articles (3745):** also an AI-curated-knowledge post, so add AI Engineering.

## How to apply

1. Review and edit the table above. It is the source of truth.
2. Back up the current assignments (`scripts/wp.sh post list --post_type=post --fields=ID,post_title,post_category,tags_input`).
3. Fix the taxonomy first (renames, merges, deletes), then assign categories and tags per post with `scripts/wp.sh --confirm post update <ID> --post_category=... --tags_input=...`.
4. Spot-check the category and tag archive pages afterwards.
